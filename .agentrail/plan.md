# launch

Saga 5 of X_eTaL-games (docs/plan.md): what must be true before a
deliberate wider launch (X_eTaL docs/research4.txt): stabilize,
synchronize, explain, one obvious path. No new games.

Every step: `just gate`, docs, a detailed commit to main including
.agentrail/, `agentrail complete`, push.

## Steps

1. about -- game titles link to Wikipedia (page glyph, new tab) or
   open a dialog on the game's history and play (Escape, click
   outside, X); game pages and catalog.
2. bench -- `just bench`: baseline, >15% regression check; numbers to
   X_eTaL saga 30.
3. start-here -- the catalog's first screen; links to the ecosystem.
4. terminal-pane -- X_eTaL's terminal pane (waits on X_eTaL saga 25).
5. promotion-blockers -- asks re-checked on the latest X_eTaL.
6. audit-tag -- cross-repo audit, a version tag.
