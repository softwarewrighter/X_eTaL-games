librarygames/sudoku/SudokuGrid.xtl

Sudoku's rules and a solver, a library: sudoku.xtl (scripted), play.xtl (at the terminal) and the web page all use these. (Named SudokuGrid because a disk that ignores case cannot hold both Sudoku.xtl and sudoku.xtl.) A grid is a vector of 81 digits, row by row, 0 an empty cell. A game's state is the puzzle's givens (81), then the grid as filled so far (81).
