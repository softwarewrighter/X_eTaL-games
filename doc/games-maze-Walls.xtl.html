librarygames/maze/Walls.xtl

The maze's rules, a library: maze.xtl (scripted), play.xtl (the game: arrow keys) and the web page all use these. A maze is a grid of blocks, wall or open, kept as one vector of 0s and 1s, row by row; a new one is carved from the game's seed with whole-array operations, and the way out is put at the open block farthest from the start. What you see is worked out the same way: the blocks ahead and to each side, every depth looked up at once, then drawn far to near. A game's state is a tuple: (the walls, where you are, which way you face (0 north, 1 east, 2 south, 3 west), the steps taken, the blocks seen, whether the mini map shows, the way out).

A new maze

ʰc̲arve : (Any a, Truthy b) => a -> b

function (private) · line 42

The walls of a new maze, carved row by row in one go (the sidewinder way): each cell joins its east neighbor at random (the top row always, the last column never), which cuts each row into runs; each run below the top row opens north from one of its cells, picked at random. The runs are a running sum of where they end; the cell picked in each run is the one with the highest random key in it, every pair of cells compared in one table.

ʰc̲arve ← { z →
  n ← CW × CH
  k ← (r̲ange n) − 1
  i ← k d̲iv CW
  j ← k m̲od CW
  east ← (j < CW − 1) ∧ (i = 0) ∨ 1 = r̲oll! n r̲eshape 2
  ends ← 0 + n̲ot east
  run ← ('+ s̲\ ends) − ends
  key ← g̲rade r̲oll! n r̲eshape 1000000
  best ← 'm̲ax r̲/₂ (0 + run '= t̲able run) × (n c̲at n) r̲eshape key
  north ← (i > 0) ∧ key = best
  cell ← 1 + (B × 1 + 2 × i) + 1 + 2 × j
  open ← cell c̲at (east r̲eplicate cell + 1) c̲at north r̲eplicate cell − B
  n̲ot (r̲ange NB) m̲ember? open
}
