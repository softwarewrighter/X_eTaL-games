programgames/trek-adventure/play.xtl

Trek adventure at the terminal, as the COR24 BASIC game plays it: "Star Trek: Decaying Orbit". Pick commands by number (8 for help); GO, TAKE and USE then ask for a room or an item number. Every command takes a turn; fix the engines before the 30 turns run out. The rules and all the text are in TrekAdventure.xtl.
