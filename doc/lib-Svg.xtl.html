librarylib/Svg.xtl

Svg: pictures written as SVG text, and the clicks on them, shared by the games played by clicking a map (capitals, stargazer). A picture's view v is x, y, width and height in the game's own units (its viewBox); layout is scaled to the view (l:u_nit), so buttons, menus and text look the same at every zoom. Rectangles are rows of x, y, width and height.
