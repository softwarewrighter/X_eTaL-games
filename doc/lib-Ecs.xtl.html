librarylib/Ecs.xtl

Ecs: an entity-component system as arrays, shared by the games built on it. A world is one matrix of numbers: a row per entity slot, and columns for its fields. Column 1 says whether the slot holds a living entity (1) or is free (0); each component then takes a column saying whether the entity has it, followed by its fields. Entities are row numbers. A system is a whole-column expression: every entity with the components it needs, at once. The macro library Ecs.xtlm, under the same alias, writes a world's layout from a list of components (getters, setters, masks); these are the functions any world uses.
