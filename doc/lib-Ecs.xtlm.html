macro librarylib/Ecs.xtlm

Ecs: its macro library -- c_omponents<, a world's layout written from its list of components. Imported with the functions, under one alias: "ec:" u_se< "Ecs". A macro is a function from the source text on each side of its call to the source that replaces the call, run before the program is compiled (X_eTaL MC10); this one creates names, which a function cannot. Names with m: are macros; those under h: are private to this file.

ᵐc̲omponents< : Char -> Char -> Char

macro · line 62

"u" ec:c_omponents< "pos:2 vel:2 hp": a world's layout from its components, each a name and a width (1 when left out). Column 1 says whether a slot is alive; each component takes a column saying whether an entity has it, then its fields. When the program is compiled it writes, for each component, a getter (u:p_os W: the column, or the columns when wider than 1), a mask (u:h_asPos W), a setter (W u:s_etPos (ids, values): the values written and the component marked present) and a remover (W u:d_ropPos ids), and u:w_orld n, a world of n slots: every column number worked out as a plain number. A malformed component stops the compiler: error[bad-components]. The left side is the namespace of the names it writes: "u" in a program, "h" (private) or "l" (exported) in a library.
