1⍝│ The dungeon's rules, a library: dungeon.xtl (scripted), play.xtl (the 2⍝│ game: arrow keys) and the web page all use these. Built on lib/Ecs: a 3⍝│ world is a matrix, a row per entity, and every rule is a system, one 4⍝│ expression over every entity with the components it needs. You, the 5⍝│ monsters and the things to pick up are entities; what each one is 6⍝│ comes from its components (dungeon.toml gives each kind its own), so 7⍝│ a new kind of monster or item is a new table there, not new code here. 8⍝│ A game's state is a tuple: (the world, the gold found, the turns 9⍝│ taken, what just happened, the map it is played on).
