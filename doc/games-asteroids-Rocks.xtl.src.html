1⍝│ Asteroids' rules, a library: asteroids.xtl (scripted), play.xtl (the 2⍝│ game: keys and the clock) and the web page all use these. Built on 3⍝│ lib/Ecs: a world is a matrix, a row per entity slot, and every rule is 4⍝│ a system over every entity at once. The entities come and go all the 5⍝│ time: every shot is spawned and spent, every rock hit is despawned 6⍝│ and its two halves spawned in the slots that freed. Which slots hold 7⍝│ what is only masks (alive, rock, shot), so the churn needs no lists 8⍝│ kept.
