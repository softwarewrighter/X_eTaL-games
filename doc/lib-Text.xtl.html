ˡj̲oin : Box Char -> Char

function · line 34

The boxed texts b joined into one text, in pairs, level by level: each level copies the text once, so n texts cost n log n, not the n squared of a reduce with c_at (X_eTaL has no built-in join yet: an ask).

      ᵗ⁼u̲se< "Text"
      ᵗj̲oin "ab" "c" "def"
abcdef
