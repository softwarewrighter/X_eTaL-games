librarygames/tic-tac-toe/TicTacToe.xtl

Tic-tac-toe's rules, a library: tic-tac-toe.xtl (scripted), play.xtl (at the terminal) and the web page all use these. The board is a vector of 9 squares, numbered row by row: 0 empty, 1 X, -1 O. X moves first.

A quick player that rates every empty square at once: four features per square (it completes a line of the mover's, it blocks one of the other's, the center, a corner), a 4 by 9 matrix, weighted 1000, 100, 10 and 5 by one inner product. ˡv̲alue : (Num a, Truthy a, Num b, Truthy b) => a -> b

function · line 81

A perfect player: minimax, written as negamax. A board's value with best play (1 X wins, -1 O wins, 0 a draw) is the winner if there is one, 0 when the board is full, else the mover's best: the mover times the largest of the mover times every move's value (every legal move tried, by recursion).

ˡv̲alue ← { b →
  w ← ˡw̲inner b
  w ≠ 0 ? w
  e ← ˡl̲egal b
  0 = t̲ally e ? 0
  p ← ˡt̲urn b
  p × 'm̲ax r̲/ p × '{ ˡv̲alue b ˡm̲ove ⍵ } e̲ach e
}
